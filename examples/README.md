# Sample SVGs

These small, synthetic illustrations let you try the converter without using private artwork. They contain no external images, fonts or scripts.

| File | Original PNG dimensions | Try this |
| --- | --- | --- |
| [transparent-icon.svg](transparent-icon.svg) | 256 × 256 | Export at 2× with a transparent background; expect 512 × 512. |
| [wide-banner.svg](wide-banner.svg) | 960 × 320 | Compare the original size with a square fixed canvas. |
| [viewbox-artwork.svg](viewbox-artwork.svg) | 640 × 360 | Check how dimensions are derived from a `viewBox`. |

## Use a sample

1. Open one of the SVG files above and choose **Download raw file**.
2. Open the [SVG to PNG converter](https://formatide.com/) and select the downloaded file, or use the samples directly in the [live browser demo](https://mcflysj.github.io/formatide-svg-to-png/).
3. Choose a size and background, convert, and inspect the PNG.

To try the app immediately without downloading a file first, choose **Try a sample** on the website.

The checkerboard in a preview indicates transparency. It is not part of the exported PNG. For more examples and troubleshooting, see the [conversion guide](../docs/svg-to-png-guide.md).
