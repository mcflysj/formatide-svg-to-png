A FEW DETAILS

Before you convert.

Does this demo upload my SVG?

No. The demo reads your file, renders it and creates the PNG in your browser. Sample files load from this site. There are no conversion requests or analytics scripts in the demo. GitHub delivers the website and handles ordinary website requests.

Is this the complete Formatide application?

This is a small, independent reference implementation for static SVG shapes. The full website supports a wider range of SVG features, batch conversion and additional formats. Its limits and privacy policy are explained on Formatide's SVG to PNG converter.

Can I reuse the code?

Yes. The files in demo/ are MIT licensed. See the module API and supported SVG subset. Keep the original license when redistributing the demo code. Formatide's name and logo identify the product.

Will transparency remove an existing white rectangle?

No. Transparency affects empty canvas space. A white shape inside the SVG remains part of the artwork. This demo does not remove backgrounds.
